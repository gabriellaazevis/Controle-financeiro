# 💰 Controle Financeiro

Sistema para gestão de finanças pessoais/empresariais desenvolvido em **PHP**, utilizando **MySQL** para persistência de dados e **Bootstrap** para a interface do usuário.

---

## 🛠️ Tecnologias Utilizadas

* **Backend:** PHP
* **Banco de Dados:** MySQL 
* **Frontend:** HTML, CSS, JavaScript, Bootstrap, FontAwesome
* **Arquitetura:** DAO (Data Access Object)

---

## 📂 Estrutura do Projeto

* `assets/` — Arquivos estáticos (CSS, JS, Fontes e dependências visuais).
* `DAO/` — Classes responsáveis pela lógica de banco de dados e manipulação de dados.
* `data_base/` — Scripts SQL com a estrutura do banco de dados e Stored Procedures.
* `template/` — Elementos visuais reutilizáveis e layouts estáticos do dashboard.
